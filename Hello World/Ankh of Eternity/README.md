# Gods of Kemet Overview

## Description

Gods of Kemet is a 2D action role playing game inspired by Egyptian mythology. The player takes on the role of a warrior chosen by the gods to fight against the forces of Chaos and restore balance to the land.

The game allows players to select between different characters with unique stats, abilities, and playstyles. Players can explore an Egyptian themed environment, battle different enemy types, use special abilities inspired by Egyptian gods, and progress through increasingly difficult waves of enemies.

Some of the features included are:

* Character selection system
* Player movement and combat
* Multiple enemy types with different behaviors
* Special abilities based on Egyptian mythology
* Health, mana, and experience systems
* Level progression
* Increasing enemy wave difficulty
* Interactive user interface
* Inventory and stats display

The purpose of creating this software was to learn more about game development and how different programming systems work together. I wanted to better understand how to create a game loop, handle player input, manage objects, create enemy AI, and build a complete interactive experience.

# Development Environment

The software was developed using Visual Studio Code as the main development environment.

Tools and technologies used:

* Visual Studio Code
* Python
* Python Arcade Library
* Git
* GitHub

The programming language used for this project was Python. The Arcade framework was used to create the game window, graphics, player input, movement, and game interactions.

This project uses object oriented programming principles including classes, objects, and data structures to manage players, enemies, abilities, projectiles, particles, and game states.
