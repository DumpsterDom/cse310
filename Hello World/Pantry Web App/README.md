# Overview

As I continue developing my software engineering skills, I wanted to create a project that combined responsive web design, JavaScript functionality, and persistent data storage into a practical real world application. My goal with this project was to strengthen my understanding of front end web development, user interaction, browser storage, and organizing larger multi page applications.

Smart Pantry is a web application that helps users discover recipes based on ingredients they already have at home. Users can add ingredients to their pantry, save them using IndexedDB browser database storage, and view recipes they are close to being able to cook. The application includes responsive design, dynamic JavaScript features, recipe recommendations, and interactive UI elements.

The purpose of creating this software was to gain more experience building modern web applications using HTML, CSS, and JavaScript while improving my understanding of DOM manipulation, responsive layouts, accessibility, modular JavaScript, and browser databases.
